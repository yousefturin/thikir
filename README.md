## Template Usage

To create a new project using this template:

1. **Clone or download this template**
2. **Run the setup script:**

   ```bash
   ./create-rn-app.sh
   ```

3. **Follow the prompts** to enter:
   - Project name
   - Display name
   - Bundle ID
   - Version

## Setup Instructions

Once your project is created:

1. Install Expo CLI:

   ```bash
   npm install expo
   ```

2. Prebuild for your target platform:

   ```bash
   npm run prebuild-ios    # For iOS
   npm run prebuild-android # For Android
   ```

3. Run the project:

   ```bash
   npm run ios     # For iOS
   npm run android # For Android
   ```

The project will open automatically once the build process is complete.
